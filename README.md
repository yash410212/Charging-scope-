# ChargeScope
Native Kotlin Android charging diagnostic app, optimized for low-overhead operation and useful on Tecno Spark 8C-class devices.

Features:
- Live voltage/current/power when exposed by Android firmware
- 60-sample average power
- Voltage history graph
- Battery percentage, temperature and charging status
- Conservative diagnostics; no fabricated measurements

Build with JDK 17 and Android Gradle Plugin 8.6.1.
